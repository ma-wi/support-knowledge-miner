## UI architecture

- [ ] Existing components were reused where appropriate.
- [ ] New shared components are justified, tested, demonstrated, and catalogued.
- [ ] Production code does not depend on a temporary prototype.
- [ ] Prototype-only dependencies were not promoted.
- [ ] Replaced components were removed or deprecated.
- [ ] Selected UI tooling is installed, locked, and owned by the correct package.

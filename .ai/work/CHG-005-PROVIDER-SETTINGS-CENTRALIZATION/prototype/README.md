# Provider settings centralization mockup

This is an isolated design artifact for
`CHG-005-PROVIDER-SETTINGS-CENTRALIZATION`.

- It is not production code.
- It must not be imported by the production React app.
- It does not connect to backend, provider endpoints, secrets, production systems or
  production data.
- It uses inline mock data and CSS only.

Open these files directly in a browser for review:

- `settings-provider-centralization-mockup.html`: streamlined Settings → Provider
  target state.
- `project-workflow-adjustments-mockup.html`: separate sketch for the new Import,
  Explorer and running-job behavior notes.
- `cluster-summary-explorer-optimization-mockup.html`: clickable options for
  Cluster-Set Summary-only regeneration and Explorer table/export layout.

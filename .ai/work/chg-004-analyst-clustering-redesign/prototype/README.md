# CHG-004 isolated design prototype

This prototype is a temporary, private design artifact for
`chg-004-analyst-clustering-redesign`.

It is not production code. It has no package manifest, no runtime dependencies, no
API calls and no access to real project data. The mock data is fake and invented.
The prototype is clickable only for navigation, dialog review and simulated
feedback states.

Open `index.html` in a browser to review the proposed information architecture and
screen composition before implementation.
